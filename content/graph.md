# The Map, as a Graph

[The Road Ahead](/06-road-ahead/) gives the chapter map as prose and a table.
This page is the same map drawn as what it actually is: a directed graph. A
shared spine — motivation, notation, the online-learning primer — forks into the
two branches, and each rung within a branch is connected to the next by the
**failure that motivates it**. The branches remerge where the toolkits do:
safety, evaluation, synthesis.

Hover a node for the chapter's one-line summary, hover an **↯ edge label** for
the full "what breaks" hand-off, and click a live chapter to open it.

<div class="demo" data-demo="chapter-map" data-wide></div>

The shape is the argument: neither branch is a detour, and the ladder ordering
within each is not chronology but *escalation* — you climb only when the rung
below breaks in a way you can name.
